Use an ESP32 or other USB bridge running the documented openrf.weather.serial.v1 firmware protocol. This does not automatically support every USB weather product. No automatic polling, USB pairing, sensor transmission or internet service.

LOCAL FILE · HISTORICAL

Verify an existing backup (preview only)

Offline restore instructions (stop OpenRF first)

The web app can only preview a backup. To recover the database, stop every OpenRF process with Ctrl+C. In Ubuntu/WSL, run the commands below using the actual downloaded backup file path. The command prompts for your passphrase without echoing it; the restore also requires you to type RESTORE OPENRF. It keeps a timestamped safety copy of the prior database.

cd /mnt/c/projects/OpenRF
python3 -m openrf.restore --preview --backup /mnt/c/Users/YOUR_USER/Downloads/openrf-private-backup.orfbak
python3 -m openrf.restore --backup /mnt/c/Users/YOUR_USER/Downloads/openrf-private-backup.orfbak

Replace YOUR_USER and the path. This restores the primary database only; maps and other stored files remain unchanged. Restart OpenRF after recovery and check your records. Never restore while the server is running.
