      External USB sensor · OpenRF Serial v1

      USER-STARTED ONLY

      A Linux USB serial port is not automatically an RF scanner. Only a controller running compatible OpenRF Serial v1 firmware can respond. Probe sends a short USB command but makes no RF observation. Capture explicitly requests one snapshot and saves real device-reported records locally, with hardware identity and clock accuracy clearly marked unverified.

      No compatible USB sensor probed. WSL may require USB passthrough; no RF readings are collected automatically.

      If a scan succeeds, compatible measurements appear in Saved, Analysis and the Map (only with an observer coordinate). No arbitrary sensor values can be uploaded through the browser. Identity, firmware and reported measurements are not cryptographically verified.
