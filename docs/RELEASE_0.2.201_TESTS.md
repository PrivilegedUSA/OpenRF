# OpenRF v0.2.201 release notes and tests

Base: complete v0.2.200 bundle. Changed files: mesh_history.py, mesh_monitor.py (new), mesh_dashboard.py, server.py, static/index.html, static/mesh-dashboard.js, version metadata, README, changelog, this document and two new tests.

The background collector uses existing local cache adapters; no automatic connects, announces, path requests, or sends. Recording remains opt-in (existing enabled preference is preserved and now applies while the backend runs). Interval 15–600 seconds, default 30. Existing retention and deduplication remain. Retention is also checked when recording is disabled. Settings changes take effect on the next worker check. Shutdown signals the worker and waits up to 12 seconds; if a snapshot remains blocked, it will not write when it returns. A completed snapshot is not proof that all protocols are available. Reticulum missing path data and failed inventory reads are reported separately. HTTP dashboard reads no longer record snapshots.

Topology shows cached Reticulum next-hop associations, not physical links or full paths; expired and unknown expiry are labeled. Up to 100 matching associations and 100 infrastructure entries display in the expandable section, with full current inventory filtering available. No verified Meshtastic/MeshCore neighbor relationships or active diagnostics are added. No new radio hardware drivers or route discovery. Historic records remain cached values rather than packet captures.

Tests executed locally: 38 mesh Python tests, 33 server tests, 1 release consistency Python test, 16 mesh JavaScript scripts plus 1 asset version script; Python compilation and JavaScript syntax check. Existing SQLite resource warnings observed. Full regression suite, live SDK/hardware, visual browser and GitHub CI not verified.

Manual acceptance: install via existing PowerShell updater; start `cd /mnt/c/projects/OpenRF && python3 -m openrf`. Open Mesh Network; confirm history off on a fresh database. Enable recording and choose interval, navigate to another workspace, wait for collector update, reopen and inspect history. Confirm unchanged caches do not create duplicate observations. Check disconnected states and that no radio connects automatically. Inspect topology with an existing Reticulum path cache; confirm expiry labels and node detail buttons. Filter infrastructure; check shared map and messaging. Disable recording and clear history; restart and verify settings. Test Surveillance Hub separately.
